# security

This is a development preview with privileged firmware integration. Report vulnerabilities privately through GitHub Security → Report a vulnerability where available. Do not post working destructive exploits, account cookies, private captures, passwords or signing files in public issues.

Review authentication host allowlists, WebView isolation, encrypted-cookie replacement, command boundaries, task/intent identity and local file ownership carefully. The optional session helper can restore or stop a captured companion through the AYN service; keep its checks and configured-companion restriction intact.

The original game and its saves remain untouched. CI uses read-only repository permissions and does not contain signing credentials. Official signed APKs are prepared locally. New firmware or account-service behavior needs actual validation before being marked supported.
