# v2.4.2 — first public source backup

New Eridu Companion for **ZZZ on AYN Thor**. This is a **development preview**, with the Hades repository's documentation/release structure adapted for ZZZ.

[downloads](https://github.com/gbppimentel-dev/new-eridu-companion/releases/tag/v2.4.2) · [setup](../SETUP.md) · [compatibility](../COMPATIBILITY.md) · [tasks](../../TASKS.md)

## what's included

- Current compact ZZZ interface: Today, Agents/Bangboo, Guide, Challenges, Calendar, Earnings and Signals.
- Local game-context observation, passive input feedback, FPS/playtime and a three-agent encounter layout.
- Task-preserving Home behavior and optional Paired Home 1.2 source/APK.
- Portable unsigned builds, external signing, source/privacy audit, synthetic UI fixtures and CI.
- Setup, privacy, architecture, compatibility, contributing and security documentation; issue forms and open validation tasks.

## public export changes

Developer UID defaults, personal fixtures, private captures, machine-specific signing references and credentials are excluded. The public app starts without a selected account. Existing saved selections/preferences remain usable with a matching signing certificate.

The public candidate is newly built from the clean export. Its exact APK has not completed fresh-account physical-device validation. Documentation images are synthetic previews. The Thor installation was not changed by this backup.
