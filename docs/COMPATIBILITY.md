The development line was used on one physical Thor. Paired Home was checked with Cocoon 3.11 and Wayfinder 1.4.1, including an existing-task resume repair. It assumes current Cocoon activity names/schema and the Thor's display arrangement. It is not general Android compatibility support.

No game-file integration is required. Do not change firmware security settings to bypass unsupported configurations. See [compatibility.json](../compatibility.json), [validation](validation-v2.7.0.json) and [open tasks](../TASKS.md).
