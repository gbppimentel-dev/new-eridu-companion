# New Eridu Companion — quick start

1. Install the signed preview APK on your own supported AYN Thor.
2. Open Account and sign in through the official HoYoLAB web flow; select the right role/region.
3. In Cocoon, pair the ZZZ entry with New Eridu Companion on the lower screen.
4. Launch through Cocoon and enter the matching game account.
5. Optional: install Paired Home and assign Wayfinder Home tap to open it on the bottom screen. Home suspends both; select the game preview to resume; use X / Close on the running-game card to quit.

The public candidate is a development preview. Recognition and service history can be incomplete; exact enemy totals are not available. The public source-built APK has not completed fresh-account device onboarding. Read the included compatibility and validation records. Never share cookies or private account captures in bug reports.
